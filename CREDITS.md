# Credits and upstream attribution

PKG Viewer is heavily based on the ideas, workflows, and implementation work in these projects:

- **PS4 PKG Validator** by Nigel1992 — https://github.com/Nigel1992/ps4-pkg-validator
- **PS4-pkg-viewer / ps4-pkgtools** by Oxwald — https://github.com/Oxwald/PS4-pkg-viewer

Their drag-and-drop inspection, metadata presentation, icon preview, package-entry viewing, and extraction workflows are direct reference points for this project. This attribution is included at the beginning of development because the project builds substantially on their work.

Before distributing any code derived from either repository, preserve the applicable copyright and license notices and confirm each repository's current license and dependency terms. Do not represent upstream code as original work.

Additional format reference: [LibOrbisPkg](https://github.com/maxton/LibOrbisPkg).
