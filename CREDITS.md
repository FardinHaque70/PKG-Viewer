# Credits and upstream attribution

PKG Viewer is heavily based on the ideas, workflows, and implementation work in these projects:

- **PS4 PKG Validator** by Nigel1992 — https://github.com/Nigel1992/ps4-pkg-validator
- **PS4-pkg-viewer / ps4-pkgtools** by Oxwald — https://github.com/Oxwald/PS4-pkg-viewer

Their drag-and-drop inspection, metadata presentation, icon preview, package-entry viewing, and extraction workflows are direct reference points for PKG Viewer. This attribution is provided because the project builds substantially on their work.

Copyright and license information for the upstream projects is retained where applicable. PKG Viewer also uses [LibOrbisPkg](https://github.com/maxton/LibOrbisPkg) as a documented PS4 PKG format reference.
